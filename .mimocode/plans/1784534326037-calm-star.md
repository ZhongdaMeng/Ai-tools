# theme.scss 全局主题变量方案

## 设计原则

1. CSS 自定义属性实现主题切换，运行时零成本切换
2. 变量统一使用 `--app-` 前缀，避免与 Ant Design 的 `--ant-` 变量冲突
3. 通过 `[data-theme="dark"]` 选择器覆盖暗色变量，JS 切换 `document.documentElement.dataset.theme` 即可

## theme.scss 结构

```scss
// ========== 默认亮色主题 ==========
:root {
  // 背景色
  --app-bg-primary: #ffffff;
  --app-bg-secondary: #f5f5f5;
  --app-bg-tertiary: #fafafa;

  // 文字色
  --app-text-primary: rgba(0, 0, 0, 0.88);
  --app-text-secondary: rgba(0, 0, 0, 0.65);
  --app-text-tertiary: rgba(0, 0, 0, 0.45);
  --app-text-inverse: #ffffff;

  // 边框 / 分割线
  --app-border-color: #d9d9d9;
  --app-border-secondary: #f0f0f0;
  --app-divider-color: rgba(0, 0, 0, 0.06);

  // 阴影
  --app-shadow-sm: 0 1px 2px 0 rgba(0, 0, 0, 0.03),
                   0 1px 6px -1px rgba(0, 0, 0, 0.02);
  --app-shadow-md: 0 6px 16px 0 rgba(0, 0, 0, 0.08),
                   0 3px 6px -4px rgba(0, 0, 0, 0.12);
}

// ========== 暗色主题 ==========
[data-theme='dark'] {
  --app-bg-primary: #141414;
  --app-bg-secondary: #1f1f1f;
  --app-bg-tertiary: #262626;

  --app-text-primary: rgba(255, 255, 255, 0.85);
  --app-text-secondary: rgba(255, 255, 255, 0.65);
  --app-text-tertiary: rgba(255, 255, 255, 0.45);
  --app-text-inverse: rgba(0, 0, 0, 0.88);

  --app-border-color: #424242;
  --app-border-secondary: #303030;
  --app-divider-color: rgba(255, 255, 255, 0.12);

  --app-shadow-sm: 0 1px 2px 0 rgba(0, 0, 0, 0.2),
                   0 1px 6px -1px rgba(0, 0, 0, 0.2);
  --app-shadow-md: 0 6px 16px 0 rgba(0, 0, 0, 0.3),
                   0 3px 6px -4px rgba(0, 0, 0, 0.2);
}

// ========== 全局基础样式 ==========
body {
  background-color: var(--app-bg-primary);
  color: var(--app-text-primary);
  transition: background-color 0.3s, color 0.3s;
}
```

## 使用方式

组件中直接引用变量：

```tsx
<div style={{
  background: 'var(--app-bg-secondary)',
  color: 'var(--app-text-primary)',
  border: '1px solid var(--app-border-color)'
}}>
  内容
</div>
```

SCSS 中也可以用（但 CSS 变量不需要 `#{$var}` 语法）：

```scss
.card {
  background: var(--app-bg-secondary);
  color: var(--app-text-secondary);
}
```

切换主题只需一行 JS：

```tsx
document.documentElement.dataset.theme = 'dark'; // 暗色
document.documentElement.dataset.theme = '';      // 亮色（回到 :root 默认值）
```
